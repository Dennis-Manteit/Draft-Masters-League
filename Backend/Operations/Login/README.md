# Login operations

The mobile login and account pages are maintained in `Frontend/Login/`. Firebase Authentication manages email and password sign-in. Keep one implementation for each flow; these folders record its backend responsibilities:

- [Login Code](Login%20Code/README.md): login operations and six-digit code primitives awaiting secure integration.
- [Create Account](Create%20Account/README.md): registration and legal consent.
- [Forgot Password](Forgot%20Password/README.md): password recovery.
- [Remember Me](Remember%20Me/README.md): session persistence choice.
