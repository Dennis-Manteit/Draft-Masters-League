# Award System

The Honourary Roll records confirmed DML awards by competition and season. The award catalogue and calculation rules belong to Operations; Programming will implement and test them once approved. No winner is published from a draft, incomplete source, or an unverified calculation.

Each published record must identify its competition, season, award, recipient, source record, rule version, approving Operations reviewer, approval time, and correction history. A record without these fields remains unpublished. Never publish private account identifiers, email addresses, or unapproved personal information.

- [DML Draft Premiership Awards](DML%20Draft%20Premiership%20Awards.md)
- [DML Fantasy Cup Awards](DML%20Fantasy%20Cup%20Awards.md)

The competition operations must provide the official award list, eligibility dates, scoring and tie-break rules, source of truth for results, and a correction process. The Commissioner must approve any award rules or winners where project instructions require approval.
